## Install and Using This Application

Install Node.js 22 or newer, then download and extract this repository. 

```sh
cd hashword
npm install
npm ci
npm run build
npm link
```

From any folder, run:

```sh
hashword
```
## Installing and Running for Development

```sh
git clone <THIS REPO>
cd hashword
npm install
npm ci
npm run dev
```
