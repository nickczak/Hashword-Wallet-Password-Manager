# Hashword API

Account authentication runs inside the same Next.js application as the website. Browser requests use the website's origin; no separate API service is required. Neon stores authentication data. No production base URL is published here.

**Authentication is implemented. Vault storage is planned and its routes below do not exist yet.**

</section>

<section id="authentication">

## Account authentication

Both clients use HTTP requests to these Better Auth routes under `/api/auth`:

| Method | Route | Purpose |
| --- | --- | --- |
| POST | `/api/auth/sign-up/email` | Register with name, email, username, and account password |
| POST | `/api/auth/sign-in/username` | Sign in with username and account password |
| GET | `/api/auth/get-session` | Read the current session; returns null when signed out |
| POST | `/api/auth/sign-out` | End the browser session |

The website calls `register`, `login`, `getAccount`, and `logout` from `src/lib/api.ts`. Its account helpers return public `id` and `name` fields; `getAccount` returns null when signed out. Raw Better Auth login/registration responses contain a nested `user` object.

Sessions use HttpOnly browser cookies managed by Better Auth. There is no CLI bearer-token flow or custom `/api/login` route. Registration requires an account password of at least 12 characters. Password-reset and email-verification delivery are not configured in the app.

</section>

<section id="errors">

## Errors

The current auth route returns a generic **503** if backend initialization or request handling throws. Check private environment settings, Neon connectivity, and the auth migration. Better Auth handles credential, validation, session, and rate-limit responses; the HTTP helpers report failed requests.

The following statuses describe the **proposed vault contract**, not existing handlers:

- **400**: invalid vault data or revision.
- **401**: missing or invalid account session.
- **403**: rejected ownership or request-origin check.
- **404**: no initialized vault.
- **409**: existing vault or conflicting revision.
- **413**: request exceeds the size limit.
